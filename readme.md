Taller 2 de Cryptologia
Este repositorio contiene las soluciones correspondientes a las diferentes partes del taller, organizadas en archivos independientes de Python.

Cada archivo parte_X.py corresponde a una parte específica del taller.

📁 Estructura del repositorio
.
├── parte_1.py
├── parte_2.py
├── parte_3.py
├── parte_4.py
└── README.md

📌 Contenido de cada parte
Parte 1 — parte_1.py
En este archivo se encuentra la solución correspondiente a la Parte 1 del taller.

Para ejecutarla:

python parte_1.py

En algunos sistemas puede ser necesario utilizar python3:

python3 parte_1.py

⚙️ Requisitos
Para ejecutar los archivos es necesario tener instalado Python 3.

Puedes comprobar la versión instalada mediante:

python --version

o:

python3 --version


Si alguno de los ejercicios requiere datos de entrada, estos serán solicitados directamente al ejecutar el archivo.
No es necesario ejecutar las partes en un orden específico, a menos que las instrucciones del taller indiquen lo contrario.
